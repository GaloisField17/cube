If none of the edges are in the correct position, we jump straight into the algorithm.

Algorithm: F2 U L R' F2 R L' U F2

When we have a solved lateral face, we rotate the cube so that face is on the Back face and then apply the following algorithm:

F2 U L R' F2 R L' U F2

We repeat the algorithm up to three times, rotating the cube so that a solved lateral face is on the Back face before each application.

No edges in correct position.

Note that the direction of U in the algorithm determines whether the edge on the Front face moves to the left or right.

Using

F2 U L R' F2 R L' U F2

places the edge on the Front face to the left, and using

F2 U' L R' F2 R L' U' F2

places it on the right.




U direction.



U' direction.

It took us 28 moves to solve this previous example by repeatedly applying the algorithm 3 times in the U direction.

We see that using the algorithm in the U' direction solves the same cube in 19 moves.
