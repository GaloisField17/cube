One Edge in Correct Position

When there is an edge in correct position, we rotate the cube so the solved lateral face is the Back face.

If none of the edges are in correction position, we jump straight into the algorithm.

Algorithm: F2 U L R' F2 R L' U F2

When we have our solved face at the back, we apply the following algorithm:

F2 U L R' F2 R L' U F2

We repeatedly apply this algorithm up to 3 times, rotating the cube so the solved lateral face is on the back each time.
