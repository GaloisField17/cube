At the end of this step, we will have correctly positioned all the corners.

We will use one algorithm repeatedly to solve the corners. Depending on the arrangement of the yellow corners, we will orient the cube correctly before each application of the algorithm.

Two Corners With the Same Facelet on One Side

If one side has two corners with the same facelet, we rotate the Up face to match the corners with the center on that face and make that face the Back face.

In short, we orient our cube as one of the following examples:

Each Side With a Different Facelet

If none of the orientations above is possible, we rotate the Up face to match one of the corners, then make that face the Back face.

In short, we orient our cube so that it matches one of the following orientations:

Algorithm: R' F R' B2 R F' R' B2 R2

After orienting the corners as described above, we will apply the following algorithm:

R' F R' B2 R F' R' B2 R2

We then rotate the Up face to bring the corners onto the appropriate faces. If we end up with two facelets of the same color on each side, the corners are correctly positioned. Otherwise, we rotate the Up face as described above and apply the algorithm again.
