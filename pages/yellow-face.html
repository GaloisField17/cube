At the end of this step, we will have completed the yellow face.

Similar to the previous step, we will use a single algorithm multiple times to complete the face. Depending on the arrangement of the yellow facelets on the corners, we will orient the cube correctly before each application of the algorithm.

No Yellow Corners on the Up Face

When there are no yellow corners facing up, we will rotate the cube or the Up face so that a yellow corner is on the Left face.

One Yellow Corner on the Up Face

When only one yellow corner faces up, we will rotate the cube or the Up face so that the yellow corner is in the Front-Up-Left (FUL) position.

All Other Cases

For all other cases, we will rotate the cube or the Up face so that a yellow corner is in the Front-Up-Left (FUL) position.

Algorithm: R U R' U R U2 R'

After orienting the cube as described above, we will apply the following algorithm:

R U R' U R U2 R'

We will repeatedly apply this algorithm until the yellow face is complete, making sure the cube is oriented correctly before applying the algorithm again.




No yellow corners on the Up face. We need to start with a yellow corner on the Left face.



Any other case. We need to start with a yellow corner in the Front-Up-Left (FUL) position.
